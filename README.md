# OpenShelf 📚

OpenShelf is a full-stack digital library platform built with Django and React.

## Features
- Role-based access (Admin & Users)
- Digital book management with PDF uploads
- User reading status tracking (Read / Reading / Not Read)
- Secure REST APIs with JWT authentication
- Admin-only book creation
- React frontend (in progress)

## Tech Stack
- Backend: Django, Django REST Framework
- Authentication: JWT
- Database: SQLite (development), PostgreSQL (planned)
- Frontend: React (Vite)
- Storage: Local (development), Cloud storage (planned)
